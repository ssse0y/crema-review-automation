# Crema Review Automation

Chrome 확장 프로그램 하나로 크리마 관리자 리뷰 업무를 자동화하는 프로젝트입니다.

## 주요 기능

- 기존 Chrome의 크리마 로그인 세션 사용
- 크리마 리뷰 관리자 페이지 직접 진입
- `신규 리뷰 관리` 및 `적립금 지급 필요` 탭 자동 탐색
- 별점이 1~3점이거나 구매 만류·분노·불만 표현이 포함된 리뷰 탐지
- 부정 리뷰 화면을 Chrome 다운로드 폴더 아래 날짜 기반 PNG 파일로 저장
- 추출한 리뷰 텍스트를 설정한 Google 스프레드시트에 기록
- 최초 설치 시 Chrome 기본 다운로드 폴더에 저장
- 필요할 때 `수정`을 눌러 캡처 하위 폴더 설정
- `부정리뷰 기록 링크`와 선택적인 시트 탭 이름 저장 및 수정
- 확장 프로그램 팝업에서 수동 점검 실행
- 지급 필요 목록의 전체 선택 체크박스와 상단 `적립금 지급` 버튼 자동 클릭
- 오류나 로그인 만료 시 적립금 지급을 수행하지 않는 fail-closed 동작
- 지급·캡처 저장 오류를 팝업에 표시하고 클릭하면 상세 원인 확인

## 현재 상태

이 저장소는 포트폴리오용 프로토타입입니다. 리뷰 탐색과 로컬 기록까지 구현되어 있습니다.

실행 순서는 부정 리뷰 캡처, Google 스프레드시트 기록, 적립금 전체 지급입니다.

## 구성

```text
extension/          Chrome Manifest V3 확장 프로그램
config.example.json 설정 예시
```

## 설치

1. [extension 폴더 다운로드](https://github.com/ssse0y/crema-review-automation/releases/latest/download/crema-review-automation-extension.zip)를 눌러 ZIP 파일을 내려받습니다.
2. 다운로드한 ZIP 파일의 압축을 풉니다.
3. Chrome에서 `chrome://extensions/`를 엽니다.
4. 개발자 모드를 켭니다.
5. `압축해제된 확장 프로그램을 로드합니다`를 누르고, 압축을 풀어 생성된 `extension` 폴더를 선택합니다.
6. 최초 설치 시 캡처는 Chrome 기본 다운로드 폴더에 바로 저장됩니다.
7. 별도 폴더에 모으려면 확장 프로그램 팝업의 `수정`을 누르고 `부정리뷰` 같은 하위 폴더명을 입력합니다.
   저장 후에는 `Chrome 기본 다운로드 폴더\\부정리뷰` 형식으로 경로가 표시됩니다.
8. `적립금 지급` 버튼을 누릅니다.

## 처리 순서

1. 부정 리뷰 판별 및 캡처본 저장
2. Google 스프레드시트 기록
3. 적립금 지급
4. 완료 상태 표시

시트 탭 이름을 입력하면 해당 이름의 기존 탭에 기록합니다. 탭 이름을 비워두면 링크의 `gid`가 가리키는 탭을 사용하며, `gid`가 없으면 스프레드시트를 열었을 때 기본으로 표시되는 탭을 사용합니다. 입력한 이름의 탭이 없으면 임의로 새 탭을 만들지 않고 중단합니다.

추출한 리뷰 텍스트는 확장 프로그램 내부에 임시 보관하지만 현재 시트로 전송하지 않습니다.

이 확장 프로그램은 예약 실행을 등록하지 않습니다. 사용자가 팝업의 `적립금 지급` 버튼을 누른 경우에만 동작합니다.

## 보안 및 운영 주의사항

- 비밀번호, 쿠키, Chrome 프로필, Google Sheet ID를 저장소에 포함하지 않습니다.
- 실제 지급 기능을 활성화하기 전에 테스트 계정이나 소수 리뷰로 검증해야 합니다.
- 같은 계정을 여러 PC에서 동시에 실행하면 중복 처리 위험이 있습니다.
- 관리자 화면 구조가 변경되면 자동화는 지급하지 않고 중단되어야 합니다.
